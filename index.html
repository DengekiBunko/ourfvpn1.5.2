💡 CORS跨域说明
由于浏览器安全限制，直接从gitlab获取配置会被拦截。工具会自动尝试多个CORS代理：
• api.allorigins.win - 推荐的免费代理
• cors-proxy.frabica.com - 备用代理
如果全部失败，请安装浏览器扩展 "CORS Unlock" 或 "Allow CORS"

📤 导出订阅

📌 v2rayN 导入说明
1. 打开v2rayN客户端
2. 点击菜单: 订阅 → 订阅设置 → 添加
3. 粘贴上述订阅链接到"地址"栏
4. 点击确定后选择: 订阅 → 更新订阅

或在v2rayN中直接: 服务器 → 剪贴板导入 → 从文本内容导入
